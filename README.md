# 렛츠콕 (letscok) 🏸

[![CI](https://github.com/jkc-mycode/letscok/actions/workflows/ci.yml/badge.svg)](https://github.com/jkc-mycode/letscok/actions/workflows/ci.yml)

배드민턴 소모임의 **보드+자석 게임 배정**을 디지털화한 실시간 코트 관리 서비스.
운영진은 태블릿의 **렛츠콕 운영**에서 4명씩 코트에 배정하고, 모임원은 폰의 **렛츠콕**에서 자기 차례를 실시간으로 확인한다.

## 시작하기 (처음 쓰는 분)

앱스토어 없이 **브라우저에서 열어 홈 화면에 추가**해 쓰는 웹앱이다. 주소: **https://letscok-web.vercel.app**

### 홈 화면에 설치하기

| 기기 | 방법 |
|------|------|
| 안드로이드 (Chrome·삼성 인터넷) | 화면에 뜨는 설치 안내의 **[홈 화면에 추가]** → 설치 |
| 아이폰·아이패드 (Safari) | 아래 **공유 버튼(□↑)** → **홈 화면에 추가** → 추가 |
| 카카오톡에서 링크를 연 경우 | 카톡 안에서는 설치가 안 된다 → 안내의 **[브라우저로 열기]** 로 나간 뒤 위 방법대로 |

설치하면 다음부터 아이콘으로 바로 들어오고, 주소창 없이 전체화면으로 열린다.

### 운영진 (태블릿)

1. `https://letscok-web.vercel.app/admin` 을 열고 홈 화면에 추가 (앱 이름: **렛츠콕 운영**)
2. 모임장에게 받은 **패스코드**로 들어간다
3. **[오늘 모임 시작]** → **[+ 코트 추가하기]** 로 오늘 쓸 코트 번호를 넣는다
4. 머리의 **[체크인 코드]** 를 눌러 4자리 코드와 QR을 모임원에게 보여 준다
5. 모임원이 체크인하면 대기 명단에 뜬다 → 셔틀콕을 받았으면 **콕 확인** → 4명을 골라(또는 추천을 받아) **[조합 만들기]** → **[코트 배정]** → 끝나면 **[게임 종료]**
   - 폰을 못 쓰는 사람은 **[수동 체크인]** 으로 대신 체크인, 처음 온 사람은 그 안의 **[신규 등록]**
6. 끝나면 **[모임 종료]** 를 두 번 누른다 — 전원 퇴장·코트 정리 후 마무리 카톡 문구가 뜨고, 그 창을 닫으면 로그아웃된다

운영 화면의 ☰ 메뉴 안 **도움말**에 버튼별 설명이 더 있다.

### 모임원 (폰)

1. 운영진이 보여 주는 **QR을 찍거나** `https://letscok-web.vercel.app/m` 을 연다 (홈 화면에 추가 권장, 앱 이름: **렛츠콕**)
2. **4자리 체크인 코드** 입력 → **이름 검색** → 내 이름 선택 (동명이인은 생년월일로 구분)
   - 처음 한 번만 개인정보 수집 동의를 받는다
   - 명단에 없으면 운영진에게 등록을 부탁한다 (스스로 가입하는 경로는 없다)
3. 체크인 뒤에는 내 대기 순서·게임 중 여부·지금 코트 상황이 실시간으로 보인다. 알림을 켜 두면 코트 배정("3번 코트로 오세요")·콕 확인·운영진 호출을 알려 준다

## 흐름

```
셔틀콕 제출 → QR 스캔 → 4자리 코드 + 이름으로 체크인
                                   ↓
렛츠콕 운영(태블릿): 대기 명단에서 4명 조합 → 코트 배정 → 게임 종료
                                   ↓
렛츠콕(모임원 폰, /m): 내 대기 순번·게임 중·경과 시간 실시간 확인
```

## 화면

| 경로 | 대상 | 설명 |
|------|------|------|
| `/admin` | 운영진(태블릿·폰) | 렛츠콕 운영 — 게임 중 / 대기 조합 / 대기 명단 3구역 보드, 패스코드 인증 |
| `/admin/history` | 운영진 | 지난 모임 기록·개인 전적·순위 |
| `/m` | 모임원(폰) | 내 상태 + 보드 읽기 전용 |
| `/m/checkin` | 모임원(폰) | 4자리 코드 + 이름 검색 체크인 |

## 주요 기능

- **실시간 보드** — 모든 변경을 전체 스냅샷으로 브로드캐스트(Socket.IO). 재연결 시 REST 재조회로 복구
- **체크인 코드** — 모임마다 4자리 코드 발급, [체크인 코드]에서 QR과 함께 표시. 코드 없이는 원격 체크인 불가
- **끌어서 옮기기(태블릿)** — 대기 명단 → 조합 빈칸 → 코트로 자석처럼 끌어 배치, 조합 순서도 끌어서 변경
- **게임 추천** — 공정성(대기시간·게임 수) + 다양성(오늘 함께 뛴 조합 회피) + 성별 복식 구성을 점수화해 후보 제안
- **AI 운영 명령(글·음성)** — "남복 짜줘", "게스트 김OO C급 추가", "누구랑 누구 대회 연습" 같은 말로 조회·게스트 추가·파트너 지정 (최대 3개를 한 문장에)
- **AI 체크인** — 신청 명단 캡처나 명령으로 여러 명을 한 번에 체크인
- **대회 연습 파트너** — 지정한 두 사람을 같은 게임에 넣도록 추천에 가점 (여건이 안 되면 평소대로)
- **휴식·선수 교체·중복 대기** — 잠깐 쉬어도 대기 시간 유지, 한 명만 교체, 4로 안 나눠지는 인원은 게임 중인 사람과 미리 조합
- **모임원 관리** — 이름 검색·탭별 인원·정렬·무한 스크롤, 같은 이름 확인, 생년월일 모를 때 비워 두기, 오래 안 온 게스트 정리
- **모임 기록·보고서** — 지난 모임·개인 전적, 마무리 문구 자동 작성
- **뒤풀이 정산** — 영수증 사진으로 품목 읽기 → 인원별 금액 계산 → 카톡 문구 복사
- **알림** — 웹 푸시로 코트 배정·콕 확인·운영진 호출 안내

## 기술 스택

| 레이어 | 기술 |
|--------|------|
| 백엔드 | NestJS 11 · Prisma 7 · PostgreSQL · Socket.IO 4 |
| 프론트 | Next.js 15 (App Router) · React 19 · Tailwind 4 · motion · qrcode.react |
| 공유 | `@letscok/shared-types` (enum · `I*` 인터페이스, zero-dep) |
| 관측 | Sentry (에러만, 선택) |

## 구조

```
apps/server            NestJS + Prisma + Socket.IO (백엔드)
apps/web               Next.js App Router (렛츠콕 운영 + 모임원 앱, PWA)
packages/shared-types  공유 타입 (enum, I* 인터페이스)
```

## 개발 환경 준비 (개발자)

```bash
pnpm install                                 # shared-types는 prepare 훅으로 자동 빌드됨
cp apps/server/.env.example apps/server/.env # DATABASE_URL / ADMIN_PASSCODE / CORS_ORIGINS
cp apps/web/.env.example apps/web/.env.local # NEXT_PUBLIC_API_URL

pnpm --filter @letscok/server exec prisma migrate dev   # DB 마이그레이션 + 클라이언트 생성
```

> Prisma 7은 스키마의 `url`을 쓰지 않는다 — CLI 연결은 `apps/server/prisma.config.ts`가 담당.
> 스키마 변경 후 컴파일 에러가 나면 `prisma generate` 재실행.

## 실행 (터미널 분리)

```bash
pnpm dev:server   # http://localhost:4000  (GET /health 확인)
pnpm dev:web      # http://localhost:3001
```
